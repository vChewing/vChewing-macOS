# CandidateWindow

用以定義與唯音的選字窗有關的基礎內容。此外，還包含了唯音自家的次世代選字窗「田所(TDK)」。

> 命名緣由：野獸先輩「田所」的姓氏。

TDK 選字窗同時支援橫排矩陣佈局與縱排矩陣佈局。

TDK 選字窗會在 macOS 10.15 與 macOS 11 系統下有下述特性折扣：

- 無法支援「根據不同的選字窗內容文本語言區域，使用對應區域的系統介面字型來顯示」的特性。
