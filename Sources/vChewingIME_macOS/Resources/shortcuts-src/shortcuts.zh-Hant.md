# 鍵盤熱鍵使用手冊（macOS）

本文對應至少唯音 4.8.7。請利用滑鼠滾輪檢視該頁面。

為了簡化下文表述，這裡介紹一下本文會用到的 macOS 的鍵盤符號。

1. 註1：BackSpace 與 Delete 採 Windows 稱謂。
1. 註2：下表內的四個方向鍵的稱謂，均為根據文字書寫順序方向而言的相對方向稱謂。
1. 註3：簡體中文使用者請注意本文「遞交」一詞的意義與「上屏」相同，英文都是「Commit」。
1. 註4：唯音不會對數字小鍵盤攔截響應（小鍵盤 Enter 鍵除外），除非有選字窗出現、且有數字小鍵盤內能輸入的字符被設為選字鍵。
1. 註5：本文下文出現的所有「數字鍵」均指主鍵盤區域的數字鍵。
1. 註6：本文用語「（內文）組字區」代指「inline composition buffer」，在微軟術語體系當中也被稱作「pre-edit area」。
1. 註7：本文用語「組音區」是指由鐵恨注拼引擎操縱的注音組音區。組音區會在使用者敲注音時出現在內文組字區內。輸入法自組音區取得讀音，在驗證其具有對應的辭典記錄之後，將其插入至組字引擎。整個內文組字區相當於組字引擎與注拼引擎的統合外在表現。
1. 註8：為了保證表達與討論的有效性、減少歧義，本文在討論前後關係時，只用「往前/往後」「前方/後方」，且僅以文字書寫方向為這些用語的方向參照。這與 Zonble 的「Before-After」前後術語邏輯體系不同：唯音在使用英文術語的情況下只用「Front / Rear (Back, Tail)」、「Forward / Backward」。
1. 註9：所謂「符號選單狀態」僅代指分類波浪符號選單。

| 熱鍵 | 模式 |

| ⌃⇧⌘ K | 輪替漢字轉換（當代繁體 / 康熙 / JIS；僅對繁體中文輸出模式有效） |

| ⌃⇧⌘ L | CNS+GBEX 模式（不另外安裝全字庫／GBEX 字型的話，某些候選字會顯示成方塊） |

| ⌃⇧⌘ M | 大寫漢字數字輸出（會將「一二三四五」轉為「壹貳參肆伍」） |
